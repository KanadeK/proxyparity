# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
ProxyParity uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-08-23

### Added

- Offline behavior profiles for curl, GNU Wget, CPython `urllib.request`, Go
  `net/http`, and Ruby `URI::Generic`.
- Cross-client DIRECT, PROXY, and ERROR decision analysis with variable,
  exclusion-rule, and reason evidence.
- Case-conflict, route-disagreement, and proxy-endpoint findings.
- Console, stable JSON, and standalone script-free HTML reports.
- Split-brain and lowest-common-denominator example scenarios.
- Credential redaction and strict scenario-boundary validation.
- Zero-runtime-dependency CLI and library package.
- Linux and Windows CI, installed-tarball smoke tests, GitHub Pages demo, and
  tag-driven GitHub Release automation.
